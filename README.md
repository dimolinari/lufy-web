# Lufy · web pública

Web estática de Lufy: el libro «El verdadero poder político. Ecuador 1972–2023» y artículos con datos oficiales del Ecuador.

- Sitio: https://dimolinari.github.io/lufy-web/
- HTML y CSS estáticos, sin JavaScript, sin cookies, sin analítica.
- Publicación: GitHub Pages desde la rama `main` (carpeta raíz).

Reglas de contenido: solo datos oficiales confirmados con enlace a la fuente, sin acusaciones, sin datos personales. Ver `historia.html`.
